# Mentora Backend Platform

Backend API for a mentorship platform where parents, students, and mentors interact.

## Tech Stack
- Node.js
- Express
- MongoDB Atlas
- JWT Authentication
- Groq LLM API

## Features
- Authentication system
- Student management
- Lesson creation
- Booking system
- Session management
- LLM text summarization

## Installation

git clone <repo>
cd mentora-backend
npm install

Create .env:

MONGO_URI=
JWT_SECRET=
GROQ_API_KEY=

npm run dev
